# Rotating 3D Globe Wireframe Animation

A collection of rotating 3D globe wireframe animations, each implemented by a different AI model.

## Variants

| File | Model |
|------|-------|
| `ChatGPT.html` | ChatGPT |
| `Claude.html` | Claude |
| `Gemini.html` | Gemini |
| `Grok.html` | Grok |
| `Kimi.html` | Kimi |
| `MiMo.html` | MiMo |
| `Qwen.html` | Qwen |

## Usage

Open any `.html` file in a browser to view the animation.
